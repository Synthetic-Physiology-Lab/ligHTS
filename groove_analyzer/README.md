# Groove_Analyzer

Groove Analyzer for periodic gel grooves
--------------------------------------------------------------

This script measures periodic groove *pitch* and *depth* from a high-SNR confocal TIFF
z-stack by:

1) Reconstructing a height map using a per-pixel z-maximum with sub-slice
   quadratic refinement.
2) Estimating dominant groove periodicity (pitch) and wave-vector angle from a
   2D FFT (used for alignment only).
3) Aligning the image with an in-plane rotation 
4) Subtracting a best-fit plane using a valley-weighted (quantile) regression to
   avoid bias from intentional grooves.
5) Measuring pitch as crest-to-crest spacing from peak detection on aligned, band-limited profiles (with FFT-seeded
   constraints), reporting a mean pitch and within-FOV distribution diagnostics.
6) Measuring depth per groove period averaging across all valid periods in the FOV, applying a pitch-dependent 
   multiplicative depth correction derived from synthetic forward-model validation
7) Building a reference groove profile and reporting NMSE and Pearson's r
   against that reference.

Definitions
-----------
- Pitch: distance between consecutive crests (local maxima) along the direction
  of periodicity after alignment.
- Depth (per period): crest height − mean(height of the two adjacent valleys), computed on baseline-corrected row-by-row
  profiles and averaged over valid periods.
- Grooved-gel height: median valley height pooled over detected groove valleys.


Normalization metrics
---------------------
- NMSE: mean((segment - reference)^2) / var(reference)
- Pearson r: correlation coefficient between each segment and the reference.

Notes
-------------------------
- Height-map reconstruction is a peak-intensity proxy assuming a single bright surface response
- Any outlier rejection is explicitly counted and reported.
- This is a domain-specific tool for periodic sinusoidal grooves acquired via confocal
microscopy with high SNR, not a general surface topography analyzer.
- The code was validated on a synthetic dataset that matches the analyzer assumption,
featuring sinusoidal grooves, tilt, in-plane rotation, and roughness,
the simulated confocal stack is a blurred delta surface with Poisson and read noise.
- From the validation on N = 240 a systematic bias on Groove depth based on Groove pitch was
observed and corrected as reported in the figure "Depth correction factor"
- The analyzer was validated using the included synthetic forward-model dataset (generated by
`synthetic_groove_generator.py` and evaluated with `synthetic_groove_validator.py`), comparing recovered pitch, depth
angle, height against known ground truth under tilt, rotation, roughness and confocal-like blur and noise.
- This code is intended for the sole use of analyzing the datasets and extracting the hydrogel
geometries displayed in figure 4 c-d-e-f, 5 d-e-f-g, and 6 a-b-c of the manuscript 
"LigHTS: Massively Parallel Biomimetic Photo-Functionalization 
for Imaging-Based Ultra-High-Throughput Screening" 





## Install

Using pip:
```bash
# Recommended:  install into a clean Python 3.11 virtual environment (venv or conda)
pip install -r requirements.txt
```

Using Conda:
```bash
conda env create -f environment.yml
conda activate groove-analyzer
```

## Basic usage

To run the script and select via GUI a folder containing stacks for gel surface geometry and height extractions:
```bash
python groove_analyzer.py
```


## Advanced Options
To reproduce synthetic dataset validation process:

a) generate synthetic dataset via:
```
python synthetic_groove_generator.py 
```

b) validate the analyzer by selecting it and the folder containing the synthetic dataset via:
```
python synthetic_groove_validator.py --gui
```
The analyzer is verified against synthetic ground truth generated from a known forward model.


## Analyzer outputs

For each image stack FILE.tif, the script creates a per-file subfolder `FILE_proc/` next to the input (plots are written unless `--no-plots` is set), containing:

- '_raw_height_map.(png|pdf)'  – raw height map
- '_height_map_aligned.(png|pdf)'  – rotation-aligned, tilt-corrected map
- '_avg_line_profile_annotated.(png|pdf)'  – average line profile with detected peaks/valleys annotated
- '_pitch_hist.(png|pdf)' – pitch distribution
- '_depth_hist.(png|pdf)' – depth distribution
- '_gel_height_hist.(png|pdf)' – grooved-gel (valley) height distribution
- '_analysis_summary.txt' – per-file metric summary (plain text)

When enough valid groove segments are found, it additionally writes:

- '_reference_groove.(png|pdf)' – plotted reference groove
- '_reference_groove.csv' – reference groove segment
- '_groove_profiles.csv'  – interpolated per-period groove segments


At the root level:
- 'groove_recap.csv' – one-row-per-file summary of all key metrics
- 'run_metadata.json' – provenance (script version, platform, parameters)
